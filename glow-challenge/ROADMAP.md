# 🌸 Glow Up Challenge: แผนโปรเจกต์ของขวัญ

> แอปชาเลนจ์ลดน้ำหนักของตัวเอง โทนพาสเทลเอิร์ธโทน
> ทำไปทีละขั้น และเรียนเป็น Dev ไปพร้อมกัน

---

## 🎯 เป้าหมายของโปรเจกต์

**เป้าหมายด้านแอป**
- ได้แอปที่ใช้จริงทุกวันบนมือถือ
- ช่วยให้ทำชาเลนจ์ได้ต่อเนื่องและเห็นความคืบหน้าของตัวเอง

**เป้าหมายด้านการเรียน**
- เข้าใจพื้นฐาน HTML, CSS, JavaScript และ Git
- อธิบายได้ว่าโค้ดทุกบรรทัดในแอปทำงานยังไง

**เป้าหมายด้านสุขภาพ** (ใช้ตัวละครอนิเมะเป็นแรงบันดาลใจ ไม่ใช่ไม้บรรทัดวัดตัวเอง)
- ลดประมาณ 0.5–1 กก. ต่อสัปดาห์
- ดื่มน้ำให้ครบ ขยับร่างกายทุกวัน และนอนให้พอ

---

## 🗺️ แผนการทำแอป (ติ๊ก ✅ เมื่อเสร็จ)

### ขั้นที่ 0: เตรียมพื้นที่ทำงาน ✅
- [x] สร้างโฟลเดอร์ `glow-challenge`
- [x] เซฟงานขึ้น GitHub ครั้งแรก (commit + push)

📚 **ได้เรียน:** Git คืออะไร, commit, push, branch

### ขั้นที่ 1: หน้าแรกของแอป ✅
- [x] สร้างไฟล์ `index.html`
- [x] ใส่หัวข้อและข้อความทักทาย
- [x] แต่งสีพาสเทลเอิร์ธโทน และทำการ์ดขอบมน

📚 **ได้เรียน:** HTML (`h1`, `p`, `div`, `class`) และ CSS (`background-color`, `color`, `border-radius`, รหัสสี)

### ขั้นที่ 2: ปุ่มนับแก้วน้ำ 💧 ⬅️ ทำต่อตรงนี้
- [ ] สร้างปุ่ม "+1 แก้ว"
- [ ] กดแล้วตัวเลขเพิ่มขึ้น
- [ ] ครบ 8 แก้วแล้วขึ้นข้อความชม

📚 **จะได้เรียน:** JavaScript เบื้องต้น ได้แก่ ตัวแปร (`let`), ฟังก์ชัน (`function`), การกดปุ่ม (`click`), เงื่อนไข (`if`)

### ขั้นที่ 3: แอปจำข้อมูลได้ 🧠
- [ ] ปิดหน้าเว็บแล้วเปิดใหม่ ตัวเลขยังอยู่
- [ ] ขึ้นวันใหม่แล้วนับแก้วน้ำใหม่

📚 **จะได้เรียน:** `localStorage` (ที่เก็บข้อมูลในเบราว์เซอร์), วันที่ (`Date`)

### ขั้นที่ 4: ชาเลนจ์ 30 วัน 📅
- [ ] แสดงตาราง 30 ช่อง
- [ ] กดแล้วติ๊กว่าวันนั้นทำครบ
- [ ] แสดงว่าทำไปแล้วกี่วันจาก 30

📚 **จะได้เรียน:** Array (รายการข้อมูล), Loop (ทำซ้ำ), สร้าง HTML ด้วย JavaScript, CSS Grid

### ขั้นที่ 5: บันทึกน้ำหนัก ⚖️
- [ ] ช่องกรอกน้ำหนักวันนี้
- [ ] แสดงประวัติย้อนหลัง
- [ ] แสดงกราฟเส้นน้ำหนัก

📚 **จะได้เรียน:** ฟอร์ม (`input`), ตัวเลข, Object, การใช้ library ทำกราฟ

### ขั้นที่ 6: Streak 🔥
- [ ] นับว่าทำต่อเนื่องมากี่วันแล้ว
- [ ] ถ้าขาดหนึ่งวัน streak เริ่มนับใหม่

📚 **จะได้เรียน:** คำนวณวันที่, คิดแบบมีขั้นตอน (logic)

### ขั้นที่ 7: ธีมอนิเมะ & เลเวลอัป 🌟
- [ ] มีตัวการ์ตูนคอยเชียร์
- [ ] ทำครบแล้วได้ EXP และเลเวลอัป
- [ ] มี animation น่ารัก ๆ

📚 **จะได้เรียน:** CSS animation, รูปภาพ, ออกแบบหน้าจอ (UI)

### ขั้นที่ 8: ใช้งานจริงบนมือถือ 📱
- [ ] จัดหน้าให้สวยบนมือถือ
- [ ] เอาแอปขึ้นเว็บด้วย GitHub Pages (ฟรี)
- [ ] เพิ่มไอคอนแอปลงหน้าจอมือถือ

📚 **จะได้เรียน:** Responsive design, การ deploy (เอาแอปขึ้นออนไลน์)

## 📚 เส้นทางการเรียนของขวัญ

เรียนตามลำดับนี้ เพราะแต่ละอย่างต้องใช้ความรู้จากอย่างก่อนหน้า

| ลำดับ | เรื่อง | คืออะไร | สถานะ |
|---|---|---|---|
| 1 | **HTML** | โครงบ้าน: บอกว่าในหน้ามีอะไรบ้าง | 🟡 เริ่มแล้ว |
| 2 | **CSS** | ทาสีและตกแต่ง: บอกว่าหน้าตาเป็นยังไง | 🟡 เริ่มแล้ว |
| 3 | **Git & GitHub** | ระบบเซฟงานและเก็บโค้ดออนไลน์ | 🟡 เริ่มแล้ว |
| 4 | **JavaScript** | สมองของแอป: ทำให้กดแล้วมีอะไรเกิดขึ้น | ⚪ ยังไม่เริ่ม |
| 5 | **Responsive design** | ทำให้สวยทั้งบนมือถือและคอม | ⚪ ยังไม่เริ่ม |

**ทำแอปนี้เสร็จแล้วเรียนอะไรต่อดี** (ค่อยว่ากันทีหลัง ไม่ต้องรีบ)
- **React**: เครื่องมือยอดนิยมสำหรับทำเว็บแอปที่ใหญ่ขึ้น
- **Backend / Database**: เก็บข้อมูลบนเซิร์ฟเวอร์ ใช้ข้ามเครื่องได้
- **React Native / Flutter**: ทำแอปมือถือจริง ๆ ลง App Store

**แหล่งเรียนฟรีที่แนะนำ**
- [freeCodeCamp](https://www.freecodecamp.org/): เรียนเป็นด่าน ๆ เขียนโค้ดในเว็บได้เลย
- [W3Schools](https://www.w3schools.com/): ตัวอย่างสั้น ๆ เข้าใจง่าย มีปุ่ม "Try it Yourself"
- [MDN Web Docs](https://developer.mozilla.org/): คู่มืออ้างอิงที่ Dev ทั่วโลกใช้

## 📖 สมุดศัพท์ Dev

| คำ | ความหมายแบบง่าย |
|---|---|
| **HTML** | ภาษาบอกโครงสร้างหน้าเว็บ |
| **CSS** | ภาษาแต่งหน้าตาเว็บ |
| **JavaScript** | ภาษาที่ทำให้เว็บโต้ตอบได้ |
| **แท็ก (tag)** | คำสั่ง HTML เช่น `<h1>` มีตัวเปิดและตัวปิด `</h1>` |
| **class** | ชื่อเล่นที่ตั้งให้กล่อง เพื่อให้ CSS ตามไปแต่งได้ |
| **รหัสสี** | เช่น `#F5EFE6` แต่ละสีมีรหัสของตัวเอง |
| **commit** | เซฟงานไว้หนึ่งจุดพร้อมโน้ต เหมือนเซฟเกม |
| **push** | อัปโหลดงานที่เซฟไว้ขึ้น GitHub |
| **branch** | ทางแยกของงาน แก้ตรงนี้แล้วไม่กระทบงานหลัก |
| **Markdown** | ภาษาเขียนเอกสารแบบง่าย เช่นไฟล์นี้ (`.md`) |

*(จะเพิ่มคำใหม่ทุกครั้งที่เรียนเจอ)*
